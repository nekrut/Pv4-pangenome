8-way multiz alignment

This track shows a genome-wide multiple alignment of all eight Plasmodium vivax strains in the pangenome — PvP01, Sal-I, PvW1, PAM, PvSY56, PvT01, PvC01, and MHC087. The hub carries one multiz track per strain; each uses its own assembly as the reference ("hinge") and stacks the other seven strains beneath it, so every base of every genome can serve as the coordinate frame.

Display Conventions and Configuration

Each row is one strain, labeled by strain name through the track's speciesLabels setting; the underlying alignment stores the rows under their GenBank assembly accessions. Aligning bases are drawn as blocks, gaps as single lines, and unaligned regions are left blank. Use the track controls to set the row order and to switch between the alignment and its summary view.

Methods

We aligned each pair of assemblies with KegAlign — a GPU-accelerated reimplementation of lastz — chained the local alignments with axtChain, and netted them with chainNet. We then combined the pairwise nets into a single eight-way alignment with multiz, producing one alignment per reference strain. Exact tool versions and parameters are recorded in the pipeline repository.
