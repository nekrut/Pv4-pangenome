Orthogroup membership

This track marks each gene with its orthogroup and with the number of strains that carry that orthogroup — from one (strain-specific) to eight (present in every strain). The coloring turns the pangenome's core-to-accessory gradient into a single browsable layer: deeply conserved genes against strain-restricted ones.

Display Conventions and Configuration

Features are genes in BED12, colored by the strain count of their orthogroup (1-8). Core genes shared by all eight strains and accessory genes found in only a few sit at the two ends of the scale.

Methods

We built a pangenome graph from the eight assemblies with PGGB — the PanGenome Graph Builder — and called orthogroups from the graph's co-membership, counting the strains present in each. Exact tool versions and parameters are recorded in the pipeline repository.
