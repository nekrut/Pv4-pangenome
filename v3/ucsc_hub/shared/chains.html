Pairwise chain alignments

This composite holds the pairwise alignment chains from the current reference strain to each of the other seven Plasmodium vivax strains in the pangenome. A chain is a run of co-linear local alignments, allowing gaps in both sequences — it captures large-scale synteny and the breaks between strains.

Display Conventions and Configuration

Each subtrack is one target strain, named "chain to <strain>". Blocks are aligned segments; thin lines connect them across gaps. Double-clicking a chain opens its details, and the companion link file resolves the gapped, base-level alignment. Subtracks are hidden by default; enable the targets you need from the track controls.

Methods

We aligned each pair of assemblies with KegAlign — a GPU-accelerated reimplementation of lastz — built alignment chains with axtChain, and selected the best chains per region with chainNet. Exact tool versions and parameters are recorded in the pipeline repository.
